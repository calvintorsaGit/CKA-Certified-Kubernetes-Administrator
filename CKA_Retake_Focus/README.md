## Rules for Practice

1. **Time every task.** Aim for ≤ 6–8 min per question.
2. **Always verify** (`kubectl get`, `describe`, `curl`, `nslookup`) before moving on.
3. **Check the context / ssh host** at the start of every question.
4. Skip anything taking > 10 min, flag it, come back later.
